Relay: A Multi-Tenant Retrieval-Augmented Generation Platform for Document-Grounded Chatbots
AUTHORS Aaditi Choramle  ·  Chitrang Choudhari  ·  Pratik Kamble  ·  Sahil Dhanavade 🎓 Guide: Prof. Swati Ghule relayy-dun.vercel.app
📄 Abstract & Problem
Large Language Models (LLMs) generate fluent answers but hallucinate and cannot be restricted to private documents. Retrieval-Augmented Generation (RAG) resolves this by embedding document chunks and conditioning the LLM on retrieved evidence.

Relay is a multi-tenant SaaS platform where signed-in owners create isolated chatbots, upload PDF / DOCX / TXT documents, and receive grounded answers with source citations. Chunks are embedded via Pinecone's hosted multilingual-e5-large and isolated by server-side chatbot_id metadata filters. Answers use OpenRouter (Llama 3.3 70B + fallbacks).

A single Next.js 15 service handles auth, ingestion, retrieval, and generation — no Python microservice. An npm widget relay-chat-widget embeds chatbots on any website.

🔍 Research Gaps Addressed
G1
Isolation under-specified — Educational RAG notebooks omit metadata filters, silently mixing tenants on shared indexes.
G2
Closed SaaS vs. incomplete prototypes — Commercial tools (Chatbase, CustomGPT) are opaque; open tutorials lack auth, isolation, or widget.
G3
Python sidecar dependency — Most student projects run FastAPI for embeddings. Pinecone hosted inference removes this entirely.
G4
Diverging answer paths — Dashboard and widget often implement separate retrieval, causing drift. Relay uses one shared function.
G5
Free-tier LLM brittleness — Rate limits crash bots. Relay adds a 4-model fallback cascade + raw-chunk safety net.
G6
Widget keys treated as secrets — pk_live_ keys are public identifiers: chat-only, CORS-bound, never exposing internal UUIDs.
⚡ Key Innovations
🛡
Logical Multi-Tenant Isolation
Shared Pinecone index; mandatory chatbot_id filter guarantees zero cross-tenant leakage — no per-tenant index overhead.
🔌
Zero-Python Hosting (Hosted Inference)
Pinecone pc.inference.embed + multilingual-e5-large — no OpenAI credits, no FastAPI sidecar, no dimension mismatch.
🧩
Embeddable npm Widget
relay-chat-widget uses Shadow DOM, server-fetched appearance, and pk_live_ auth — copy-paste embed on any site.
🔄
4-Model Fallback Cascade
OpenRouter cascade: Llama 3.3 70B → GPT-OSS 120B → DeepSeek-R1 → raw chunk excerpt — never a blank answer.
📦
Chunked File Uploads
Files >3.5 MB sliced client-side & reassembled server-side — bypasses Vercel's 4.5 MB limit without cloud storage costs.
